# Source-bound collection and independent review

Run `python scripts/build_collection_handoff.py` to check the committed ledger against its declared native inputs. Run with `--write` only after inspecting native changes. CI checks replay and adversarial decisions.

`research/collection-work-ledger.json` indexes declared record views, source leads and open tasks; `review/collection-packet.json` provides six review dimensions and native routes. Neither certifies completeness, independent witnesses, permissions or scientific approval. Digital entries, derivative sentences and physical objects remain distinct units.

A qualified reviewer must inspect cited editions/images, record competing readings and provenance, and complete a copy of `review/collection-decision-template.json`. Validate it with the builder's `--decision` option; syntactic validity is not verification of reviewer identity or independent expertise. Human maintainer acceptance and native admission gates remain necessary. Do not invent review receipts, reinterpret an access blocker as an exhausted source, or release upstream content from a project license. Linear A restricted derivatives are only available through the authenticated local route.
