# eDiAna adapter reuse

The current project proves an end-to-end source-preserving workflow against an eDiAna snapshot. Future eDiAna corpora should reuse the acquisition and validation pattern, not assume identical linguistic conventions.

Candidate next corpora include Lydian, Sidetic, Pisidian, Cuneiform Luwian, Hieroglyphic Luwian, and Palaic. Each must receive a corpus-specific profile and tests before import.

This repository remains the reference implementation until the factory code is promoted into a standalone shared package.
