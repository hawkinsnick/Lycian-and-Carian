# 1.0.0 — attributed eDiAna source snapshot

453 catalogue entries: 187 Lycian, 264 Carian and two separately partitioned
Milyan entries. All source responses retained with requests, attribution,
rights evidence and hashes. Line strings and upstream annotation matrices
are available in structured records; JSON, JSONL and CSV exports roundtrip.
Deleted, uncertain and aggregate source entries and 18 Greek-script rows
are excluded from default frequencies.

Offline validation, negative integrity tests and CI guard source replay,
partition boundaries and deterministic exports. Source catalogue coverage
is complete for the selected snapshot. Independent critical-edition review,
unique-monument counts and exhaustive world-corpus coverage are not claimed.
Data CC BY-SA 4.0; code MIT. Cite eDiAna and the principal editions retained
in each entry, as well as this versioned adaptation.
