# Roadmap

0.1: rights and public catalogue capture. 0.5: source adapters and language
partitions. 0.9: exports, negative tests and source replay. 1.0: published,
verified source snapshot and researcher workflow.

After 1.0: document-level object concordance, newer Lycian edition comparison,
independent source-reading review, script inventories with cited values,
and only then appropriate linguistic benchmarks. Catalogue completeness
and world-corpus completeness are separate measures.
